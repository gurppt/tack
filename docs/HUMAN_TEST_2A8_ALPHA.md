# Small-alpha acceptance — Phase 2A8

Use owned test boards and keep a copy of valuable files. Physical Windows desktop,
artist feel and a real two-computer trusted LAN remain human acceptance gates.
The previous whole-system crash is undetermined, not attributed to Tack.

- [ ] About shows the owner logo, Cargo version, short commit and Dev identity.
- [ ] Preferences defaults to Dev; manual Check for Updates is near About.
- [ ] A settled local board makes no GitHub request and starts no updater/media process.
- [ ] Controlled published Dev release: Current / Available, Download and Cancel.
- [ ] Wrong hash or interrupted download is refused; staged retry is recoverable.
- [ ] Restart applies a verified portable package, keeps one previous version,
      relaunches, and preserves boards, profile/keysets and personal PNG artwork.
- [ ] A non-writable install offers manual download without elevation.
- [ ] F10 always opens the menu, independently of custom keysets or right-click bindings.
- [ ] Canvas tool cursor / toolbar/menu/panel pointer / restored canvas cursor;
      toolbar scale 1×/2×/3× remains independent of native DPI.
- [ ] Single image outline is obvious; every group member is highlighted with one handle set.
- [ ] Multiple Scribble strokes remain one draft; zoom/pan retains them; Enter ends one object.
- [ ] Scribble move/resize/rotate/flip/duplicate/order/color/undo/save/reopen.
- [ ] Eraser splits only the target Scribble; Escape cancels; release is one Undo.
- [ ] Merge preserves selected stroke appearance/order and restores originals with one Undo.
- [ ] Ctrl+L with existing selection: dotted pixel lines, chain cursor, Frame hover,
      matching press/release, confirmation, prior tool restored, Escape cancels.
- [ ] Link without selection: toolbar acquisition uses normal pick/marquee/group rules.
- [ ] Frame move carries images/group/note/shapes/Scribble; Frame resize leaves them unchanged.
- [ ] Unlink and Frame deletion preserve positions; Ungroup retains links;
      grouping conflicting parents is explicitly refused.
- [ ] Shared clients converge on link/unlink/move/erase/merge and Undo/Redo;
      conflicting leases refuse/cancel clearly. Major-2 peers are refused.
- [ ] Local-minimal retains local save/open/edit and has no collaboration/update UI.
- [ ] Alpha-default shares/joins on actual Windows and a real two-computer trusted LAN.

Automated controlled-helper tests cover hash, interrupted stage, rollback and
personal-data isolation. They do not substitute for a real published test release,
physical Windows interaction or power-loss testing.
