# Image interaction — Phase 1C

Implementation plan, written before code:

1. Extend metadata commands with a bounded flat image-edit batch, atomic rollback and inverse order. Bound history by entries and bytes; track edit generation for asynchronous Save.
2. Keep selected IDs and gesture snapshots in app-local state. Reuse `ImageRenderData` for previews; geometry functions operate on existing `Transform`/`Crop`. Test local/world/UV invariants independently.
3. Extend the existing action/keymap/input boundary with captured gesture tokens and cancellation. Keep dynamic navigation modifiers (including late Alt); route all product pointer gestures through one adapter.
4. Render restrained canvas overlay primitives in the common GPU pass. UI sizes are logical preferences multiplied once by native scale; hit testing converts physical→world in f64.
5. Compose DocumentEditor into the existing product window. Save an owned metadata snapshot on one worker, preserving indexed original payloads, with exact-generation dirty acknowledgement.
6. Add persistence/lifecycle/native interaction tests and reproducible scenarios; compare against frozen Phase 1B, independently review and fix findings, then report/commit/push and stop.

Contract: selection is transient and never changes document order. Reverse document order decides topmost geometric hit; missing previews remain eligible. Empty click clears; Shift toggles; empty drag creates marquee. Selected-object drag preserves multi-selection. Preview owns starting and current render records for selected images only, allocated at begin; pointer updates reuse memory, with no source/storage access. Release produces one flat batch, including crop+transform. Cancel discards preview without touching durable state.

Single-object resize uses its rotated local basis. Corner handles keep ratio, edge handles change one axis, opposite edge/corner stays fixed; Alt chooses center pivot at begin. Multi-selection uses its world-axis bounding rectangle: move preserves spacing, resize is uniform about opposite corner/center, rotate uses the shared rectangle center and preserves relative rotations. Crop is single-image only: normalized UV and world center/size change together so retained source pixels keep their world positions, including flips/rotation. Crop handles can expand back toward original UV bounds. Nonfinite/out-of-world updates leave the preceding valid preview intact.

Navigation takes precedence over image preview; starting pan or wheel cancels preview. Hold actions capture original release tokens despite keymap/modifier changes. Escape, focus loss, cursor capture loss, minimization and coordinate-system changes cancel. UI handle tolerances stay in logical screen units at every zoom. Durable history remains outside renderer; overlays and camera focus do not enter it.

Save owns one snapshot/generation and worker. CRC-valid persisted previews use the opened generation; repaired previews are pinned as opened, checksummed files on the worker (at most 128 extra descriptors), so cache eviction cannot break a save. Additional disposable repairs can be omitted and regenerated on reopen. New requests while active do not enqueue. Geometry remains editable; acknowledgement clears dirty only if the saved generation still equals editor generation. Failed save keeps dirty and reports an error. Storage's atomic publication preserves the previous file on pre-publication failure. Original bytes are copied from the stable opened file, never reimported from a missing/changed link. Corrupt disposable overviews may be omitted and repaired on reopen. Shutdown joins the owned save outside the event/render loop.

Focus clamps to the existing camera center limits. Rotation begun very near the pivot uses horizontal motion to avoid an atan2 jump at zero radius; otherwise it follows angular pointer motion. Nearest handle wins when hit targets overlap at low zoom. Middle pan has priority regardless of press order. Title status is cached and applied only when changed, with one owner; repeated X11 property updates are prohibited. See the [desktop freeze incident](../INCIDENT_2026_10_03_DESKTOP_FREEZE.md).
