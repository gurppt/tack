# Image interaction reference — Phase 1C

Checked 2026-10-03. Reference: legally installed PureRef 2.1.3 (distribution package), isolated settings and two generated 320×240 grid PNGs; no proprietary scene/assets inspected. Native X11 captures: `/tmp/tack-phase1c-reference-2s7xggcj/` (local, disposable).

The [image handbook](https://www.pureref.com/handbook/images/) describes left selection, Shift multi-selection, empty-space marquee, corner scaling, Alt scaling about center, Ctrl drag rotation, crop gizmo mode and non-destructive cropping. Move uses left drag. Group transforms have shared pivots; individual transforms are additional commands. Crop modifiers can constrain aspect. These are workflow references, not implementation material.

[Official shortcut inventory](https://www.pureref.com/handbook/shortcuts/all-shortcuts/) documents Ctrl+Alt+Shift+C crop mode, Alt+Shift+H/V flips, Alt+T sampling, Ctrl+Alt+Shift drag opacity, Ctrl+A, Delete, Ctrl+Z and Ctrl+Shift+Z. The [navigation handbook](https://www.pureref.com/handbook/navigation/) documents middle/Alt-left pan, wheel zoom, Space/double-click focus. [Settings](https://www.pureref.com/handbook/settings/) establish configurable gizmo size and isolated `-s` settings; [automation](https://www.pureref.com/handbook/automation/) permits loading our generated fixtures.

Native observations: selecting the red image produced eight small circular handles and an outline, with the blue image unselected. Opposite-corner resize kept the upper-left at (140,80) while the initial 320×240 box became approximately 442×332 despite a non-proportional pointer delta: default aspect lock. Shift corner drag also retained aspect in this probe. Crop mode showed broad edge/corner affordances. Moving its right edge from x460 to x380 removed two grid columns while the remaining grid spacing and left edge stayed fixed. Double-click framed the image to nearly the whole window. Handle diameter was visually about 10 physical pixels at this desktop scale; no claim about fractional-DPI behavior. Alt-center and Escape probes were inconclusive (modifier/window-lock interference); do not infer their exact native semantics.

Tack decisions: corner resize locks aspect; edge handles resize one axis. Alt with a handle chooses center resize at gesture start. Ctrl-drag rotates; Ctrl+Alt-drag scales uniformly; crop mode is single-image only with edge/corner handles. Selection does not bring forward. Sampling cycles Default→Smooth→Nearest; all three semantic actions exist. Double-click fits without PureRef's second-click restoration. Escape, focus loss and capture loss always discard preview. Marquee uses transformed-quad intersection. No snapping, individual-pivot group scaling, crop pan/zoom shortcuts or view rotation in this phase.

Additional deliberate differences: Shift move-axis constraints and crop aspect/square modifiers are deferred; Shift currently controls selection. Global Default sampling resolves to smooth in this slice; preferences UI is deferred.
